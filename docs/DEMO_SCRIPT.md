# 4 分钟现场演示脚本

## 演示前 10 分钟

1. `npm run check`，确认测试与构建通过。
2. `npm run dev`，打开 `http://127.0.0.1:4310/#/settings`。
3. 主演示选择“本地 Ascend”并检查连接；不可用则选择“演示回放”。
4. 检查浏览器摄像头、麦克风和扬声器权限。
5. 只使用虚构资料和带“早/下午”文字的演示盒，不展示真实药物和家属隐私。
6. 打开 `#/demo`，保持浏览器 100% 缩放和稳定网络。

## 0:00–0:35 问题与边界

讲述：

> 认知障碍长者真正困难的往往不是不会操作，而是当下忘了下一步。守忆灯塔不是聊天框，也不替代医生；它只用家属确认过的记忆，在合适的时候轻声提醒。

指向界面的“非医疗诊断工具”“只复述家属录入的信息”。

## 0:35–1:15 记忆先于模型

切到“记忆中心”：

- 展示长者称呼和沟通偏好。
- 展示药盒标签、08:30 时间与摆放位置。
- 展示眼镜常放位置。
- 快速点到“授权与数据”，说明默认只存当前浏览器，公网需要单独授权。

讲述：

> 模型不是凭空猜，它只看得到家属授权并录入的最小必要事实。

## 1:15–2:40 全模态一镜到底

回到“演示台”，点击“开始陪伴”，依次触发：

1. “触发晨间日程”：助手主动提醒查看“早 · 08:30”标签。
2. 举起“下午”演示盒，点“展示拿错标签盒”：助手只纠正标签不一致，不识别药片。
3. 说“是右边这个吗”，点“用户打断并追问”：展示全双工打断与短句恢复。
4. 问“我的眼镜在哪”，点“询问眼镜位置”：调用家属上传的位置记忆。

真模型模式下，“日程”“重复”和“记忆”按钮会向模型发送明确的业务事件；“拿错标签盒”按钮只显示演员提示，必须等待模型依据真实画面自然响应。任何按钮都不会代替模型写入视觉证据。回放模式播放固定语音，并在面板中清楚标记。

## 2:40–3:25 不确定时交还给人

点击“模拟未明确确认”。切到“家属端”，展示：

- 状态为“待家属查看”，不是“危险”或“漏服”。
- 事件摘要说明未得到明确确认。
- 家属可以人工接手并确认。

讲述：

> 我们把最难的产品判断放在这里：AI 可以提醒和解释，但不替人做高风险结论。

## 3:25–4:00 总结

> 同一份授权记忆贯穿家属配置、长者陪伴和事件回看；确定性规则守住时间与状态，MiniCPM-o 负责持续看听、主动说话和被随时打断。这就是守忆灯塔的完整闭环。

## 现场故障话术

- 本地模型不可达：切换“演示回放”，明确说“现在展示离线业务闭环，模型实测记录和接口配置在项目验收页”。
- 摄像头不可用：继续音频流程，说明权限状态已被单独显示，不用预录视频伪装实时画面。
- 公网排队：不临时上传真实资料；切回本地或回放。

## 可选加分场景

主线完成后如仍有时间，可触发“厨房离开前复核”和“夜间起身陪伴”。两者都只给单步骤提示：回放明确是模拟线索；真模型模式下按钮只给演员提示，必须等待现场音视频驱动模型，不能把导演点击写成视觉证据。
