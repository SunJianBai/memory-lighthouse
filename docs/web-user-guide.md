# Web 使用指南维护说明

## 页面与入口

- 地址：`/openBMB/guide`，公开可读，不依赖登录或家庭数据。
- 首页“使用指南”、家属工作区侧栏及移动端“更多”提供入口。
- 陪伴端在新标签页打开指南，避免离开正在运行的陪伴页面。

## 内容组织

1. 快速开始：注册验证、创建家庭、绑定设备、授权并开始。
2. 设备绑定图：家属生成 → 陪伴端提交 → 家属批准。
3. 两端说明：家属管理与陪伴设备的界面示意。
4. 功能与操作：六项功能，展开后显示步骤及使用限制。
5. 常见问题：账号、验证码、激活、设备权限与远程呼叫。

使用功能名称作为标题，不采用宣传语；默认仅显示摘要。示意图使用可缩放的 HTML/CSS 与现有图标，明确标注示例，不包含真实家庭资料、激活码或通话画面。

## 修改位置

- `apps/client-web/src/pages/guide-content.ts`：步骤、功能说明和常见问题。
- `apps/client-web/src/pages/GuidePage.tsx`：章节结构、流程图及界面示意。
- `apps/client-web/src/styles.css`：以 `.guide-` 为前缀的响应式样式。
- `apps/client-web/src/pages/GuidePage.test.tsx`：公共访问、导航、折叠和使用边界检查。

更新说明时应核对对应页面的实际按钮、权限和行为。当前教程以 Web 端为例，不能将计划中的能力写成已实现能力。

## 基础检查

运行 `npm run test` 和 `npm run build`。浏览器检查桌面与窄屏、目录跳转、折叠展开、键盘焦点，以及无需登录访问。该页面不需要新增接口、数据库表或线上数据。
