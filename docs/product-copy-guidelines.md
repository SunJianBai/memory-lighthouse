# 产品界面文案规范

本规范适用于守忆灯塔 Web 用户端。界面标题用于标识页面与功能，不承担宣传或完整说明的作用。

## 标题层级

- `h1`：产品名称或当前页面名称，例如“守忆灯塔”“家属端”“陪伴设备激活”。
- `h2`：页面中的功能模块名称，例如“家庭待办”“快捷操作”“授权管理”。
- `h3`：具体资源、表单或内容分组名称。
- 每个页面只设置一个主要 `h1`；标题层级按顺序使用，不跳级。

## 文案放置

- 功能说明、操作步骤和使用条件放在标题后的正文中。
- 成功、错误、等待和空数据使用状态提示，不写成宣传式标题。
- 避免在标题中使用完整句子、标点结尾、第二人称劝导或拟人化表达。
- 技术实现细节只在排查问题确有必要时显示；普通提示优先说明用户可执行的下一步。
- 产品名称、页面名称和导航名称应保持一致。

## 示例

| 不推荐标题 | 推荐标题 | 正文说明 |
| --- | --- | --- |
| 登录后管理家人和陪伴设备。 | 家属端 | 登录后可管理家庭资料和陪伴设备。 |
| 把此浏览器激活为陪伴设备 | 陪伴设备激活 | 扫描二维码或输入动态码激活此设备。 |
| 没有可呼叫的陪伴设备 | 无可用陪伴设备 | 请先激活设备并确认设备在线。 |
| 记得住生活细节，也懂得何时轻声提醒。 | 守忆灯塔 | 长者陪伴、记忆档案、日程提醒和家庭远程通话。 |
