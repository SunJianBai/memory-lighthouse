# 管理端设计约束

- 风格：数据密集、克制、可信；侧栏 + 顶栏 + 主内容区。
- 色彩：安定蓝为主色，绿色表示成功，琥珀表示待处理，红色只用于危险与原文检查。
- 排版：系统中文字体优先；ID、哈希与统计数字使用等宽/表格数字。
- 间距：4/8px 节奏；普通交互目标不小于 44px。
- 无障碍：skip link、语义标题、可见焦点、表格 caption、ARIA live 状态、键盘可操作。
- 响应式：桌面固定侧栏；小于 900px 改为抽屉；数据表在窄屏提供可聚焦横向滚动区。
- 动效：只用于状态变化，160–220ms；`prefers-reduced-motion` 下关闭。
- 数据边界：不造假数据；空、失败、无权限、生产锁定均显示独立状态。
- 原文检查：默认生产隐藏；开发显式启用；双人审批；查看前二次确认；水印；60 秒清屏；不持久化。
