# 守忆灯塔

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

家属管理长者照护信息与远程联系；长者使用陪伴设备；管理员维护账号、家庭、设备和模型配置。

## Product Purpose

提供长者陪伴、记忆档案、日程提醒、家庭待办与远程通话。用户应能直接找到当前任务，并清楚知道操作的结果。

## Operating Context

本文件记录 Web 产品事实，以及本轮经用户确认的跨端边界。客户端为 React，管理端为 Vue，Android 为原生 Kotlin / Jetpack Compose；Android 不改为网页包装应用。三端视觉可以统一，操作方式遵循各自平台习惯。

## Capabilities and Constraints

- 邮箱或用户名密码登录、邮箱验证码验证；家庭成员、长者、陪伴设备及隐私授权管理。
- 一个账号可切换家属与陪伴模式，一台陪伴设备对应一名长者；支持二维码或动态激活码。
- 记忆档案、日程与家庭待办、远程通话、账号与安全设置、使用指南。
- 此轮保留所有业务能力、路由及权限判断，不改授权含义，不接触真实家庭数据。
- 2026-11-03 用户在聊天中明确选择 B「家庭档案」，并要求改造正式 Web、管理端及原生 Android 的全部页面。此前独立风格展示继续保留，不再收集页面点击选择。
- 设计方案中的人物、记录与设备均使用明确标注的合成示例，不代表线上数据。
- 方案预览只展示、不收集选择；只有用户在聊天中明确表达选哪套才算批准。页面点击不能被视为选择，浏览后不能自动关闭展示服务。

## Brand Commitments

保留“守忆灯塔”名称和现有品牌图标（当前 Web BrandMark 使用 Lightbulb 图形）。使用正式、明确的产品文案，不将宣传语或实现细节作为页面标题。可保留“MiniCPM-o 4.5 全双工全模态应用”。用户已授权重新设计配色、布局、导航呈现和组件。

## Product Principles

- 任务和记录优先于装饰。
- 状态与操作结果清楚，隐私授权含义不变。
- 跨端统一，但不牺牲原生交互和可访问性。
- 设计选择先预览，正式替换后再部署。

## Accessibility & Inclusion

长者端优先大字、清晰对比和易触达操作。颜色不作为唯一状态标记；支持键盘焦点、减少动态效果、手机窄屏和系统文字缩放。
